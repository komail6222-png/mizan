# RASID | Risk-aware energy planning

Compare two risk settings, examine the hourly battery schedule, and download the independently checked plan with its scenario costs.

This interactive exhibit replays recorded local CPU runs on generated fixtures. The page re-verifies every SHA-256 digest and Ed25519 receipt in your browser and exports them as JSON. The full source release supplies the input importer, live job API, baselines and verification script.
